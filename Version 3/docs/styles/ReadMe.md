# styles

Dieses Verzeichnis enthält alle Stylesheets, JavaScript-Dateien und Bilder, die für die Dokumentation verwendet werden.

## Dateien
- `husst_roboto_orange.css`: CSS-Stylesheet für die Dokumentation.
- `cooltoc.js`: JavaScript-Datei für das Verzeichnis.
- `HUSST-logo-1-300x129.png`: Projektlogo zur Anzeige über dem Inhaltsverzeichnis.
- `type.svg`: Symbol zur Einbindung in automatisch generierte Dokumentationen.
