# xsl

Dieses Verzeichnis enthält alle XSL-Stylesheets und Testdateien, die für die Transformation der .xsd-Dateien verwendet werden.

## Dateien
- `DvToADoc.xsl`: XSL-Stylesheet zur Transformation der .xsd-Dateien.
- `Spielwiese.xsl`: Test-Stylesheet, um neue Transformationen zu testen.
- `HUSST_Dok-Testfaelle.xsd`: Testdatenstruktur, um die Haupttransformation zu testen.
